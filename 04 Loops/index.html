Теоретичні питання

1. Що таке цикл у програмуванні?

Цикл — це конструкція, яка повторює блок коду кілька разів: доки виконується умова або доки не буде перебрано всі елементи.

2. Які види циклів є в JavaScript?

  • for — повторює код із лічильником; зручно, коли відома кількість повторень.
  • while — повторює код, поки умова істинна; умова перевіряється перед кожною ітерацією.
  • do...while — спершу виконує код, а потім перевіряє умову, тому тіло виконується щонайменше один раз.
  • for...of — перебирає значення ітерованого об’єкта, наприклад елементи масиву.
  • for...in — перебирає перелічувані ключі об’єкта.

3. Чим відрізняються цикли while і do...while?

У while умова перевіряється до виконання тіла — якщо вона одразу хибна, цикл не запуститься. У do...while умова перевіряється після тіла, тож код виконається принаймні один раз.

while (умова) {
  // може не виконатися жодного разу
}

do {
  // виконається щонайменше один раз
} while (умова);

Практичні завдання

1. Числа в діапазоні

Введи два числа. Якщо значення не є числами, програма попросить ввести їх ще раз. Потім вона виведе всі цілі числа в діапазоні від меншого до більшого включно.

for (let number = Math.ceil(min); number <= max; number++) {
  console.log(number);
}

2. Парне число

Введи ціле парне число. Якщо введено не число, не ціле або непарне число, програма проситиме повторити введення.

while (number % 2 !== 0) {
  // попросити ввести число ще раз
}
