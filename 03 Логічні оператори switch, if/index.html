Кодова арена

Дізнайся, як логічні оператори, умови if та switch керують виконанням коду. Прочитай теорію, спробуй вправи й перевір знання у вікторині!

Теорія

Логічний оператор виконує операцію над логічними значеннями або умовами та повертає результат, який можна використати в розгалуженні програми.

  • && — логічне «І»: результат істинний, якщо істинні обидві умови.
  • || — логічне «АБО»: результат істинний, якщо істинна хоча б одна умова.
  • ! — логічне «НЕ»: змінює істинне значення на хибне і навпаки.

if виконує блок коду, коли умова істинна; else if перевіряє іншу умову, а else спрацьовує, якщо попередні умови хибні. switch вибирає дію за точним збігом значення з одним із варіантів case. Команда break завершує відповідний варіант, а default обробляє інші значення.

Практичні завдання

1. Визначення вікової групи

Введи вік. Програма перевірить, що введено число, і повідомить, чи є користувач дитиною, підлітком або дорослим.

const input = prompt("Скільки вам років?");
const age = Number(input);

if (input === null) {
  // Введення скасовано
} else if (input.trim() === "" || !Number.isFinite(age)) {
  alert("Введено не число.");
} else if (age < 12) {
  alert("Ви дитина.");
} else if (age < 18) {
  alert("Ви підліток.");
} else {
  alert("Ви дорослий.");
}

2. Кількість днів у місяці

Введи назву місяця українською. Результат з’явиться в консолі розробника (натисни F12, щоб її відкрити). Для лютого враховано високосний рік.

switch (month) {
  case "січень":
  case "березень":
  case "травень":
  case "липень":
  case "серпень":
  case "жовтень":
  case "грудень":
    console.log("31 день");
    break;
  case "квітень":
  case "червень":
  case "вересень":
  case "листопад":
    console.log("30 днів");
    break;
  case "лютий":
    console.log("28 або 29 днів");
    break;
  default:
    console.log("Такого місяця не знайдено.");
}
